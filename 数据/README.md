# 全国省份数据包（数据清单）

本目录存放网站切换为河北单省数据源之前的**全国统一数据库存档**。数据覆盖 31 个省份，主体年份为 2017–2025，并合入了本地已有的 2026 增量。

数据版本：`2026.11.19-1`。库内容指纹：`890775fc9a34b218d7e9731f70b4e2675166e9458b751109fc1bb66cd55624ea`。

## 缺少的数据

- **`plan_code` 2026 年全缺**：没有免费的结构化招生计划源，本包未补。
- **一分一段不完整**：只有 30 省有结构化分数段；`image_only` 表记录 42 条图片版/未发布分段，未转成可查询数据。
- **2023–2025 部分单元格缺数据**：`gap_list` 记录 17 条缺口，原因是源字段为空、源表未提供或仅图片发布；未用插值或外部数据填充。
- **2026 为增量而非完整年度**：部分省份的投档线/专业分为本地增量或抽样，质量表中标为 `partial` / `sampled`，不等同于官方完整年度数据。
- **河北 2024 专业录取分缺失**：官方 xlsx 只提供投档最低分，不是录取分，因此未作为 `major_adm` 写入本包。
